# return-language
📖 Return Language Cheat Sheet (Шпаргалка)
1. Переменные и Массивы

j A = 10 — создать переменную A со значением 10.

j Arr[5] — создать массив из 5 ячеек.

Arr[0] = 99 — записать 99 в первую ячейку массива.

2. Математика

A++ — увеличить A на 1.

A-- — уменьшить A на 1.

A ** 5 — умножить A на 5.

A // 2 — разделить A на 2.

C = A + B — сложить A и B, результат в C.

3. Вывод и Ввод

allow: "Hello " + A — вывести текст и переменную на экран.

allow.time(time) — вывести системное время.

P("go"): ... exit p; — ждать, пока пользователь введет слово "go".

4. Условия и Циклы

E(A > 5): ... exit E; — если A больше 5, выполнить код.

E(A > 5 & B < 10): ... exit E; — если A больше 5 И B меньше 10.

L(A < 10): ... exit L; — цикл: пока A меньше 10, выполнять код.

5. Функции

root("my_func"): ... exit root; — создать функцию.

play("my_func"); — вызвать функцию по имени.

6. Железо (Hardware)

clow(BLUE) — залить экран синим (доступны RED, GREEN, BLUE и др.).

asm("hlt") — вставить чистый ассемблер.

port(0x60) -> A — прочитать байт из порта ввода-вывода.

poke(0xB8000, 65) — записать число 65 прямо в память.

halt(); — остановить процессор.
